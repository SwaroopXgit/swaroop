# Swaroop - Cosmic Gesture Web Experience

A browser experience that uses your camera and hand gestures to create:
- A **space-like interactive particle field**
- A **movable hologram core**
- **Pinch-controlled hologram intensity and scale**

## Run locally

```bash
python3 -m http.server 8000
```

Then open: `http://localhost:8000`

> Allow camera access for full gesture controls. If hand tracking is unavailable, mouse fallback control is enabled automatically.
